# Trailkit — аддон WoW Forever (панели аспектов и ловушек охотника)
- Lua 5.1, современное Mainline API. Никакого Classic API, никаких внешних библиотек.
- Secret values: не сравнивать и не считать значения кулдаунов/аур без issecretvalue. Где можно — отдавать во встроенные фреймы Blizzard.
- Боевой лог не использовать.
- Secure-кнопки менять только вне боя (InCombatLockdown).
- Спеллы — только в Spells.lua.
- Комментарии в коде на русском, README на английском, общение на русском.
- Без оверинжиниринга: минимально рабочее решение, правки маленькими шагами.
